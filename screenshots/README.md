# Screenshots

このディレクトリには、Chrome Web Store用のスクリーンショットを配置します。

## 必要なスクリーンショット

### 1. メインスクリーンショット（必須）
- **ファイル名**: `screenshot-1.png`
- **サイズ**: 1280x800px または 640x400px
- **内容**: 拡張機能のポップアップ画面
  - 検索機能を使用している状態
  - 更新ボタンが表示されている状態
  - できれば進捗表示も含める

### スクリーンショットの撮り方

1. **拡張機能を起動**
   - NotebookLMページで拡張機能アイコンをクリック
   - ポップアップが表示される

2. **画面をキャプチャ**
   - macOS: Cmd + Shift + 4 でキャプチャ
   - Windows: Snipping Tool または Win + Shift + S
   - スクリーンショットツールを使用してポップアップ全体をキャプチャ

3. **リサイズ（必要に応じて）**
   ```bash
   # macOSの場合
   sips -z 800 1280 screenshot.png --out screenshot-1.png

   # またはオンラインツール（https://imageresizer.com/）を使用
   ```

4. **配置**
   - このディレクトリに `screenshot-1.png` として保存

### オプション: 追加のスクリーンショット

より詳しい説明のために、複数のスクリーンショットを追加できます：

- `screenshot-2.png`: 全ソース更新モード
- `screenshot-3.png`: 指定ソース更新モード（検索結果表示中）
- `screenshot-4.png`: 更新実行中の進捗表示

### スクリーンショットの品質ガイドライン

- **解像度**: 高解像度（Retina表示対応）
- **内容**: 実際の使用例を示す
- **背景**: NotebookLMページが見える状態が理想的
- **テキスト**: 読みやすいフォントサイズ
- **言語**: 日本語で統一

### Chrome Web Storeでの表示

スクリーンショットは、Chrome Web Storeのアイテムページで以下のように表示されます：
- 掲載ページのメインビジュアル
- スライドショー形式で複数枚表示可能
- ユーザーがインストール前に機能を確認できる

## 注意事項

- スクリーンショットに個人情報が含まれないように注意
- NotebookLMの実際のコンテンツが見えないようにする
- 著作権やプライバシーに配慮する
